# BongoCat-Lan Checklist

## MVP 必需

- [x] 定义联机协议：版本号、客户端 ID、昵称、消息类型、时间戳、payload。
- [x] 定义输入状态数据结构：键盘按下/释放、鼠标按下/释放、鼠标移动、手柄按钮/摇杆。
- [x] Rust 后端实现 UDP 局域网广播发送。
- [x] Rust 后端实现 UDP 监听接收。
- [x] 加入本机客户端 ID，避免接收并处理自己发出的广播。
- [x] 将本机 `device-changed` 事件转发为局域网输入消息。
- [x] 将本机 `gamepad-changed` 事件转发为局域网输入消息。
- [x] 接收远端输入消息后，通过 Tauri event 发给前端。
- [x] 新增联机 Pinia store，管理本机状态、远端客户端列表、远端输入状态。
- [x] 主窗口支持渲染多只猫：本机猫 + 远端猫。
- [x] 远端猫能根据远端键盘/鼠标/手柄状态触发对应动作。
- [x] 远端客户端超时后移除或标记离线。
- [x] 偏好设置中增加联机开关。
- [x] 同步多语言文案。

## 协议与稳定性

- [x] 增加 hello/heartbeat/input/leave 等消息类型。
- [x] 对未知协议版本做忽略或降级处理。
- [x] 对非法 payload 做边界校验，不能影响本机运行。
- [x] 处理重复消息。
- [x] 处理乱序消息。
- [x] 处理丢包后的状态恢复，例如 heartbeat 携带当前按键快照。
- [x] 限制广播频率，尤其是鼠标移动和手柄摇杆。
- [ ] 增加远端状态节流或插值，避免远端猫抖动。

## 用户体验

- [x] 偏好设置显示联机状态：关闭、监听中、已发现客户端数量。
- [x] 支持设置昵称或设备名。
- [x] 支持配置端口，至少保留默认端口。
- [x] 远端猫有可区分标识，例如昵称、小标签、位置偏移。
- [x] 多个远端客户端同时在线时，每个客户端对应独立猫猫。
- [ ] 联机关闭时停止广播、停止监听并清理远端猫。
- [x] 网络错误或端口占用时给出可读提示。

## 隐私与安全

- [x] 只同步输入状态，不同步具体文本内容。
- [x] 不同步剪贴板、窗口标题、进程信息、文件路径。
- [x] 远端消息只能驱动远端猫展示，不能触发本机系统输入或快捷键。
- [ ] 不引入公网服务器、账号系统、云同步或遥测。
- [x] 对消息大小做上限限制。
- [x] 对客户端数量做合理上限，防止局域网异常广播拖垮 UI。

## 跨平台

- [ ] macOS 验证 UDP 广播、监听、权限提示。
- [ ] Windows 验证防火墙场景和端口监听。
- [ ] Linux(x11) 验证广播地址、输入监听与窗口展示。
- [ ] 处理同机多开场景。
- [ ] 处理多网卡场景，至少明确默认行为。

## 验证标准

- [ ] 单机模式不受影响。
- [ ] 两台客户端启动后能互相发现。
- [ ] A 按键/鼠标/手柄时，B 出现远端猫动作。
- [ ] B 按键/鼠标/手柄时，A 出现远端猫动作。
- [ ] 任一客户端退出后，对方远端猫在超时后消失或离线。
- [ ] 异常消息、旧协议消息、超大消息不会导致崩溃。
- [x] `pnpm lint` 通过。
- [x] `pnpm build` 通过。
- [ ] `cargo check --workspace` 通过。
